# Taptop CSV ⇄ Коллекции

Расширение для Chrome. Загружает CSV в коллекции (CMS) Taptop и выгружает коллекции в CSV. Работает внутри редактора Taptop под твоей сессией, логин и токены не нужны.

## Установка
1. Распаковать архив.
2. Открыть `chrome://extensions` и включить «Режим разработчика».
3. Нажать «Загрузить распакованное» и выбрать папку `extension`.
4. Открыть проект в редакторе Taptop. Внизу слева появится кнопка «CSV ⇄ Коллекции». Панель также открывается кликом по иконке расширения.

## Импорт
1. Выбрать коллекцию. Кнопка «Шаблон CSV» скачивает файл с заголовками полей этой коллекции.
2. Выбрать CSV. Кодировка UTF-8 или Windows-1251, разделитель `;`, `,` или Tab определяются автоматически.
3. Проверить сопоставление колонок с полями. Оно подставляется по названиям, а для Title и Slug ещё и по синонимам: «Название», «Заголовок», «Slug», «URL».
4. Выбрать режим:
   - **Создать + обновить**: если элемент с таким ключом уже есть, он обновляется, если нет — создаётся новый;
   - **Только создать**;
   - **Только обновить**: строки без совпадения пропускаются.
   Ключом служит Slug или Title.
5. Нажать «Проверить без записи» и посмотреть лог. Затем «Импортировать».

### Новые поля из колонок CSV
Если в коллекции нет поля под колонку, выбери для неё «＋ Создать новое поле». Кнопка «Создать поля для всех несопоставленных» делает это для всех колонок без пары. Расширение предложит название (по заголовку колонки) и тип (по значениям колонки): число, дата, да/нет, ссылка, картинка по URL, rich text или текст. И название, и тип можно поменять. Для полей-связей нужно выбрать коллекцию, на которую они ссылаются.

Сами поля создаются только при «Импортировать», перед этим расширение спросит подтверждение. «Проверить без записи» проверяет значения так, будто поля уже есть, но в Taptop ничего не создаёт.
6. Обновить страницу редактора (F5).

Строки с ошибками пропускаются. Кнопка «Отчёт об ошибках» выгружает CSV с номером строки и причиной ошибки.

## Форматы значений
| Тип поля | Что писать в ячейке |
|---|---|
| Title | текст, до 200 символов, обязателен для новых элементов |
| Slug | латиница, цифры, `-`, `_`. Если пусто, Taptop сгенерирует slug из Title |
| Текст | как есть |
| Rich text | HTML (`<p>`, `<b>`, `<a>`…) или обычный текст: пустая строка между абзацами даёт новый абзац |
| Число | `12500`, `12 500,50`, `12500.5` |
| Дата | `16.10.2026`, `16.10.2026 14:30`, `2026-10-16`, unix-время |
| Ссылка | URL |
| Переключатель | да/нет, 1/0, true/false, вкл/выкл |
| Изображение | ссылка `https://…` (скачивается и загружается в Taptop) или имя файла, если сами файлы выбраны в поле «Картинки» |
| Связь | Title, slug или id элемента связанной коллекции |
| Множ. связь | несколько значений через `\|`, например `Стрижка \| Мытьё` |

Пустая ячейка по умолчанию не трогает поле. Если включить галочку «Пустые ячейки очищают поле», пустое значение стирает поле.

## Экспорт
«Экспорт коллекции в CSV» выгружает все элементы в UTF-8 с разделителем `;`, файл открывается в Excel. Связи выгружаются названиями, картинки — полными URL. Этот файл можно отредактировать и загрузить обратно.

## Ограничения
- Расширение использует внутренний API редактора (`/-/x-api/v1/protected/?method=mosaic/collection/...`). Публичного API у Taptop нет. Если Taptop изменит этот API, расширение придётся обновлять.
- По справке Taptop в коллекции не больше 1000 элементов. Код редактора блокирует создание после 2500. Расширение предупреждает при превышении 1000 и останавливается на 2500.
- Перед работой с боевым проектом сделать экспорт коллекции, чтобы была резервная копия.

## Разработка
`test/mock_server.py` — имитация API редактора. Формы запросов и ответов в нём сняты с реального HAR. Запуск: `python3 test/mock_server.py 8765`, затем открыть `http://127.0.0.1:8765/-/cms/v1/mosaic/?ver_id=1&access=u%3B1`.
